# GitKalkulator
## Opis projekta
GitKalkulator je preprost kalkulator, napisan v programskem jeziku C++. Projekt je namenjen učenju uporabe Gita, GitHuba in osnovnih postopkov razvoja programske opreme.
## Funkcionalnosti
- Seštevanje
- Odštevanje
- Množenje
- Deljenje
- Izračun ostanka pri deljenju
## Tehnologije
- C++
- Git
- GitHub
- Visual Studio Code
## Namestitev in zagon
1. Prenesemo repozitorij:

   `git clone git@github.com:Gerca1234/GitKalkulator.git`
2. Odpremo mapo projekta:

   `cd GitKalkulator`
3. Prevedemo program:

   `g++ kalkulator.cpp -o kalkulator`
4. Zaženemo program:

   `./kalkulator`
## Struktura projekta
- `kalkulator.cpp` – izvorna koda kalkulatorja
- `.gitignore` – pravila za ignoriranje nepotrebnih datotek
- `.github/` – konfiguracija GitHub Actions in Dependabota
- `README.md` – dokumentacija projekta
